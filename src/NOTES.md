# Alcance académico y técnico

Temas del material de BDA: PostgreSQL y planes (6, 7, 9 y 11); XML (2 y 3); MongoDB y Redis (10); paralelismo y distribución (4 y 5); recuperación (8); OLAP y minería (11 y 12).

Este laboratorio usa ejemplos originales con datos ficticios. PGlite sí ejecuta consultas SQL mediante un motor PostgreSQL local. MongoDB y Redis son intérpretes/simuladores con subconjuntos limitados. OLAP y reparto entre nodos también se simplifican para fines didácticos. Un plan EXPLAIN no constituye medición de un servidor real con datos masivos. No se reparten apuntes privados ni soluciones del campus.
